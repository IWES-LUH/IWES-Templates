\chapter{Tables}
\label{cha:Tables}

Alongside illustrations, tables are a useful means of presenting content clearly or integrating data. They should be centered and separated from the text. Tables should not be surrounded by text.

Like figures, tables should be labeled. The table caption should be placed above the table, e.g. table \ref{tab:Beispieltab-1_EN}. It is centered and justified with a hanging indent so that the actual caption begins flush left after the numbering, see also the rules for figures in section \ref{cha:Images_EN}. 

\begin{table}[!htbp]
	\centering
	\caption[Two-column sample table with different column alignments]{Two-column sample table with different column alignments (left column right-aligned, right column left-aligned). The label has a hanging indent}.
	\begin{tabular}{rl}
		\toprule
		\textbf{work step} & \textbf{partial work step} \\
		\midrule
		Simple work step & something simple \\
		& Something else simple \\
		&\\
		Somewhat more complicated work step & preparatory work \\
		& Anything complicated \\
		& Something more complicated \\
		& Final work that is even more complicated \\
		\bottomrule
	\end{tabular}%
	\label{tab:Beispieltab-1_EN}%
\end{table}%


The caption must clearly describe the table content so that the table can be understood on its own without continuous text. Any symbols used (formula symbols) must be introduced in the figure caption. For long table captions, \LaTeX{} provides the option of defining a short form for the table index, just as for figures.

\begin{addmargin}[1cm]{1cm}
	\textit{\textbf{Note:} Each table must be referenced in the body text. Tables that are not referenced must be removed}.
\end{addmargin}

If a table is taken from another source, this must be referenced in the table caption. However, you should avoid copying tables from other sources unchanged, as otherwise a uniform table style is not possible. It is better to take only the content of a table from a source and integrate it into a self-designed table. In this case, the source must also be referenced, e.g. in the form " `Contents from [XX]" ' (where \textit{XX} is a placeholder for the reference number).

Tables must not protrude beyond the text width. In wider tables, the font size can be reduced within limits, see table \ref{tab:Beispieltab-2_EN}. However, care must always be taken to ensure legibility. The font size in table \ref{tab:Beispieltab-2_EN} is borderline. The font size should not be smaller. If the tables are very wide, they should be included in landscape format.

There are countless ways in which a table can be designed in detail. For a uniform layout of tables, vertical lines should be avoided if they are not absolutely necessary. A horizontal line should be placed above and below the column labels and below the last table row, whereby the top and bottom lines should be slightly thicker, see table \ref{tab:Beispieltab-1_EN} and table \ref{tab:Beispieltab-2_EN}. Blank lines can be inserted for vertical delimitation, see table \ref{tab:Beispieltab-1_EN}. Alternatively, additional thin horizontal lines can be useful for dividing table blocks, see table \ref{tab:Beispieltab-3_EN} and table \ref{tab:Beispieltab-4_EN}.

The horizontal alignment of columns (left-aligned, right-aligned or centered) must be considered on a case-by-case basis. The tables \ref{tab:Beispieltab-1_EN} to \ref{tab:Beispieltab-4_EN} show the various options, also in combination. Sometimes it can be useful to connect some rows vertically. An example of this is shown in table \ref{tab:Beispieltab-4_EN}. There, the cells in the first two columns are connected vertically, so that a row division is recognizable in the third column. In this case, the thin horizontal lines make the table easier to read.
